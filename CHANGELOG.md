# Changelog

## 0.2.0

voiced-deck:

- `doctor` checks every requirement and prints the fix for your OS.
- `setup` installs what is safe to install and prints the rest.
- `pack-single` writes one self-contained HTML with the voice embedded, so the deck plays wherever it is opened. `--bitrate` shrinks it with ffmpeg.

## 0.1.0

voiced-deck: the first release. The deck engine and template, the CLI from script to render, the presenter tests, the PNG-packed delivery and the Hivewise demo.
